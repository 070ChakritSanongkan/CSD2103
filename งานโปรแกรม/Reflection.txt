ตอนที่ 11: ใช้ GenAI ช่วยตรวจโค้ด

Prompt ที่ใช้ถาม AI:
ช่วยตรวจสอบโค้ด Java โปรแกรมหาคะแนนรวมและตัดสิน Pass หรือ Fail ว่ามีข้อผิดพลาดหรือไม่ และช่วยอธิบายแบบเข้าใจง่ายด้วย

1. AI พบข้อผิดพลาดอะไรหรือไม่
ตอบ: AI ตรวจแล้วไม่พบข้อผิดพลาดที่ทำให้โปรแกรมทำงานไม่ได้ โปรแกรมสามารถรับคะแนน คำนวณคะแนนรวม และตรวจสอบ Pass หรือ Fail ได้

2. คำแนะนำของ AI ถูกต้องหรือไม่ เพราะเหตุใด
ตอบ: ถูกต้อง เพราะคำแนะนำตรงกับการทำงานของโปรแกรมและเงื่อนไขที่โจทย์กำหนด

3. นักศึกษาแก้ไขโค้ดตาม AI หรือไม่
ตอบ: แก้ไขเล็กน้อยตามคำแนะนำของ AI เพื่อให้โค้ดอ่านง่ายและตรวจสอบได้ง่ายขึ้น

4. นักศึกษาได้เรียนรู้อะไรจากการใช้ AI ตรวจโค้ด
ตอบ: ได้เรียนรู้ว่าการใช้ AI ช่วยตรวจสอบโค้ดสามารถช่วยหาจุดผิดพลาดและช่วยให้เข้าใจคำสั่งต่าง ๆ ได้ง่ายขึ้น แต่ต้องอ่านและตรวจสอบเองด้วย

5. มีข้อควรระวังอะไรในการใช้ AI ช่วยเขียนโปรแกรม
ตอบ: ไม่ควรเชื่อคำตอบของ AI ทั้งหมด ต้องตรวจสอบโค้ดและทดลองรันด้วยตนเอง เพราะบางครั้ง AI อาจให้คำตอบที่ไม่ตรงกับโจทย์หรือมีข้อผิดพลาด

Reflection หลังทำใบงาน

1. ส่วนใดของ Java ที่นักศึกษายังไม่มั่นใจมากที่สุด
ตอบ: เรื่อง Array และ Method เพราะต้องเข้าใจการเก็บข้อมูลและการส่งค่าระหว่างส่วนต่าง ๆ ของโปรแกรม

2. โจทย์ข้อใดยากที่สุด เพราะเหตุใด
ตอบ: โจทย์ค้นหาข้อมูลใน Array เพราะต้องใช้ทั้ง Array การวนซ้ำ และการตรวจสอบเงื่อนไขพร้อมกัน

3. การทบทวน Java ครั้งนี้ช่วยเตรียมตัวเรียน Algorithm อย่างไร
ตอบ: ช่วยให้เข้าใจพื้นฐานการเขียนโปรแกรมมากขึ้น และสามารถนำเงื่อนไข การวนซ้ำ และ Array ไปใช้ในการเขียน Algorithm ได้

4. นักศึกษาคิดว่า Java ส่วนใดสำคัญที่สุดต่อการเรียน Algorithm
ตอบ: การใช้เงื่อนไข การวนซ้ำ และ Array เพราะเป็นส่วนที่ใช้บ่อยในการแก้ปัญหาและเขียน Algorithm

5. นักศึกษาจะฝึกเพิ่มเติมเรื่องใดก่อนเรียนสัปดาห์ถัดไป
ตอบ: จะฝึกเรื่อง Array, Loop และ Method เพิ่มเติม รวมถึงลองเขียนโปรแกรมโจทย์ง่าย ๆ ด้วยตัวเองเพื่อให้คล่องมากขึ้น
